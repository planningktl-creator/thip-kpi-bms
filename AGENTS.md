# THIP KPI BMS

This repository is a React/Vite BMS Marketplace frontend for THIP KPI quality intelligence. Keep HOSxP read-only, keep SQL behind the registered query layer, and never commit session credentials, marketplace tokens, PHI, or raw patient rows.
