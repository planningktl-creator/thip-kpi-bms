# สถานะผลลัพธ์ 232 ตัวชี้วัด THIP (ปีงบประมาณ 2569)

รายงานนี้สร้างจากข้อเท็จจริงใน repository + ผลรวมที่วัดได้จริงจาก HOSxP (aggregate เท่านั้น)
