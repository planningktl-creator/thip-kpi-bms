# THIP KPI — ชุดคำสั่งผลงานรายปี (เทียบเป้าทุกปีใน HIS)

เอกสารนี้เป็นคู่มือใช้ชุดคำสั่ง **รายปี** ของตัวชี้วัด THIP ทั้ง 232 รหัส
(177 รหัสจาก HOSxP + 55 รหัสจากตารางภายนอก `reporting.thip_external_facts`)

## 1) แนวคิดของชุดนี้ — "เป้าหมายทุกปีใน HIS × ผลงานของปีนั้น"

เดิมชุดคำสั่งจะคืนค่าตาม **รอบรายงาน** ของตัวชี้วัด (รายเดือน 12 งวด / ไตรมาส / ครึ่งปี / รายปี)
ชุดนี้เปลี่ยนมุมมองเป็น **รายปีงบประมาณ** โดย:

- **เป้าหมาย** อ่านสดจากตาราง `kpi_moph` ของ HIS ผ่าน `kpi_moph_guideline`
  (จับคู่ชื่อ guideline ที่มีรหัส THIP เช่น AA0101) แล้วอ่านตัวเลขเป้าตามลำดับ
  `kpi_moph_number_result` -> `number_mean` -> `number_c` -> `number_b` -> `number_a`
- **ปีที่แสดง** = ทุกปีที่มีการบันทึกเป้าใน `kpi_moph` ของรหัสนั้น
  รองรับทั้งปี พ.ศ. (24xx/25xx) และ ค.ศ. (20xx จะถูก +543 ให้อัตโนมัติ)
  และบวกปีงบตั้งต้นของไฟล์ (ค่าใน `thip_params` ค่าเริ่มต้น 2569) เป็น fallback
  กรณีโรงพยาบาลยังไม่บันทึกเป้า
- **ผลการดำเนินงาน** คำนวณจากข้อมูลจริงของ **ปีงบนั้นเท่านั้น** (ไม่สะสมข้ามปี)
- คอลัมน์เทียบเป้า `vs_target_pct` (%) และ `status` (on-track / watch / action /
  unbenchmarked / no-data) คำนวณให้พร้อมใช้

## 2) คอลัมน์ผลลัพธ์ (11 คอลัมน์)

| คอลัมน์ | ความหมาย |
|---|---|
| indicator_code | รหัสตัวชี้วัด (เช่น AA0101) |
| indicator_name_th / indicator_name_en | ชื่อตัวชี้วัดไทย / อังกฤษ |
| period_start | วันเริ่มปีงบของแถวนั้น (1 ต.ค. ของปีงบ) |
| fiscal_year | ปีงบประมาณ (พ.ศ.) |
| numerator / denominator | ผลการดำเนินงาน (ตัวตั้ง/ตัวหาร) ของปีนั้น |
| value | ค่าตัวชี้วัดของปีนั้น |
| target | เป้าหมายของปีนั้นจาก kpi_moph (NULL = ยังไม่บันทึกเป้า) |
| vs_target_pct | ร้อยละเทียบเป้า (NULL เมื่อไม่มีค่าหรือไม่มีเป้า) |
| status | สถานะเทียบเป้า |

## 3) วิธีใช้ใน Navicat

1. เปิดไฟล์รายรหัสจากโฟลเดอร์:
   `Documents/Navicat/PostgreSQL/Servers/test/ktlhos/public/THIP_<รหัส>_รายปี.sql`
2. กดรันได้ทันที (เป็น SELECT อ่านอย่างเดียว) — จะเห็น 1 แถวต่อ 1 ปีงบที่มีเป้า
3. ต้องการเปลี่ยนปี fallback: แก้เลขที่ `FROM (VALUES (2569)) AS v(fiscal_year)`
   (มีผลเฉพาะกรณี kpi_moph ยังไม่มีเป้าของรหัสนั้น)
4. ต้องการทั้งชุดในคำสั่งเดียว: ใช้ไฟล์
   `Documents/Navicat/PostgreSQL/Servers/test/ktlhos/00_ชุดรวมทั้งชุด_232_ทุกรหัส_รายปี.sql`
   (คำสั่งเดียวรวม 232 รหัสด้วย UNION ALL — ใช้เวลารันนานกว่าปกติมาก)

## 4) การตรวจสอบที่ผ่านมา (จากหลักฐานการรันจริง)

- รันครบทั้ง 232 รหัสบนฐานข้อมูลทดสอบ พร้อมเป้าจำลอง 2 ปี (2568/2569): **232/232 ผ่าน**
  (ตรวจ: จำนวนแถว = จำนวนปีเป้า, เป้าต่อปีถูกต้อง, vs_target คำนวณถูก, status ไม่ว่าง)
- ทดสอบแยกหลายปี (2567 พ.ศ. + 2568 พ.ศ. + 2026 ค.ศ.->2569): ได้ 3 แถว แยกปีถูกต้อง
- ไฟล์ทั้งหมดผ่านการตรวจอักขระ WIN874 (client_encoding ของไคลเอนต์ไทย HOSxP)
- ต้นทางของชุดนี้คือชุดรายเดือนที่ผ่านการพิสูจน์แล้ว (`docs/thip-queries-monthly-2569`)
