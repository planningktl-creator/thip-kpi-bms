# THIP KPI — ชุดคำสั่ง "ผลรายปี × เป้าหมายทุกปีใน HIS"

ชุดนี้คือรูปแบบ **รายปี** ของคำสั่ง THIP KPI ทั้ง 232 รหัส (232 = 177 HOSxP + 55 external)
สร้างจากการแปลงชุดรายเดือนที่ผ่านการตรวจสอบแล้วแบบ deterministic (facts branch ไม่ถูกแก้ไข)

## แนวคิด

- **เป้าหมาย**: อ่านจากตาราง `kpi_moph` ของ HIS ต่อปีงบ (คอลัมน์ result -> mean -> c -> b -> a)
  ปีที่แสดง = **ทุกปีที่มีการบันทึกตัวเลขเป้า** ใน kpi_moph (รองรับทั้ง พ.ศ. 24xx/25xx และ ค.ศ. 20xx -> +543)
  บวกปีงบตั้งต้นของไฟล์ (thip_params) เป็น fallback กรณีโรงพยาบาลยังไม่บันทึกเป้า
- **ผลการดำเนินงาน**: คำนวณจากข้อมูลจริงของ **ปีงบนั้น ๆ เท่านั้น** (ไม่สะสมข้ามปี)
- แต่ละรหัสจะได้ 1 แถวต่อ 1 ปีงบ; เทียบเป้าเป็น `vs_target_pct` และตัดสิน `status` ให้อัตโนมัติ

## คอลัมน์ผลลัพธ์

| คอลัมน์ | ความหมาย |
|---|---|
| indicator_code | รหัสตัวชี้วัด |
| indicator_name_th / indicator_name_en | ชื่อไทย / อังกฤษ |
| period_start | วันเริ่มปีงบ (1 ต.ค. ของปีงบนั้น) |
| fiscal_year | ปีงบประมาณ (พ.ศ.) |
| numerator / denominator | ผลการดำเนินงานของปีนั้น |
| value | ค่าที่คำนวณได้ของปีนั้น |
| target | เป้าหมายของปีนั้นจาก kpi_moph (NULL = ยังไม่บันทึกเป้า) |
| vs_target_pct | ร้อยละเทียบเป้า (NULL เมื่อไม่มีค่า/เป้า) |
| status | on-track / watch / action / unbenchmarked / no-data |

## การนำไปใช้

1. รันไฟล์รายรหัสที่ `01-hosxp/` หรือ `02-external/` ใน Navicat (แก้ปีงบตั้งต้นที่
   `FROM (VALUES (2569)) ...` เฉพาะกรณีเป็น fallback — ปีที่แสดงจริงมาจาก kpi_moph)
2. หรือใช้ไฟล์รวม `03-shared/00_ชุดรวมทั้งชุด_232_ทุกรหัส_รายปี.sql` (UNION ALL ทั้ง 232 รหัส)
3. ไฟล์ทั้งหมดเป็น **read-only SELECT** และผ่านการตรวจ cp874 สำหรับไคลเอนต์ WIN874 ของ HOSxP
